# বাজার দর (BazarDor)

**বাজার দর (BazarDor)** is a responsive web application that helps users explore product prices and market information in Bangladesh. Users can browse products, view category-wise information, and manage their account securely with Better Auth.

## Technologies Used

- **Next.js** — Building the application and server-rendered pages.
- **Next.js App Router** — Page routing and dynamic routes.
- **TypeScript** — Type safety and maintainable code.
- **Tailwind CSS** — Responsive styling and UI design.
- **Better Auth** — User registration, sign-in, sessions, and profile management.

## Key Features

1. **Product Price Information** — Browse products and their latest available prices.
2. **Category-wise Browsing** — Explore products by category using dynamic routes.
3. **Responsive Design** — User-friendly interface for mobile, tablet, and desktop.
4. **Authentication** — Register and sign in securely using Better Auth.
5. **Profile Management** — View profile information and update your name.
